# 学習ログ・備忘録 (Learning Logs)

このディレクトリ（`04-learning-logs/`）は、開発を進める中で得られた**「技術的な気づき」「ハマったポイントとその解決策」「AIとのディスカッションで深まった理解」**を記録する場所です。

## 目的
- 単なる「作業メモ」ではなく、「なぜこう動くのか」「どうしてこの設計にした方が綺麗なのか」といった**深い洞察**をストックする。
- 将来、似たようなエラーや設計の迷いが生じた際のリファレンスとする。

## 記録のルール
1. **仕様の重複禁止 (DRY)**
   - ドメインのルールや規約など、`02-domain-models/` や `00-meta/` に書くべき正式な仕様をここに散ぼさないこと。
2. **節目での記録**
   - 新しい概念（例：FSDにおける特定のレイヤー間のやり取りのコツ、Reactでの複雑なゲームループの最適化手法など）を確立したタイミングで記録する。

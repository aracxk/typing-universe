# ユビキタス言語 (Ubiquitous Language)

タイピングゲームプラットフォーム「Typing Universe」における、チーム（AIとユーザー）間およびコード内で使用する統一用語集です。
複数種類のゲームが存在するため、ゲーム固有の概念と共通の概念を厳密に区別します。

---

## 1. プラットフォーム共通 (Core / Shared)

| 日本語名 | 英語名 (Code) | 説明 |
| :--- | :--- | :--- |
| **タイピング宇宙** | `TypingUniverse` | 本プラットフォームの名称。 |
| **プレイヤー** | `Player` | ゲームをプレイするユーザー。今回はログイン機能がないため、ローカルで完結する匿名プレイヤーを指す。 |
| **ゲームセッション** | `GameSession` | プレイ開始から終了までの**共通のスコア・プレイ時間・プレイヤー情報**を管理する概念。※ゲームの進行自体は管理しない。 |
| **スコア** | `Score` | ゲームの得点。Value Objectとして扱い、負の数にはならない。 |
| **タイプ速度** | `WPM` | Words Per Minute。タイピングの指標。 |
| **ターゲット単語** | `TargetWord` | 出題される単語そのもの（不変な値オブジェクト）。 |
| **アクティブワード** | `ActiveWord` | プレイヤーが現在入力中の単語。**現在の入力状態（バッファ、マッチ位置）**を持つミュータブルなEntity。 |

---

## 2. ゲームモード別用語

### A. インベーダーモード (Invader Mode)

文字を持った敵が上から迫ってきて、正しくタイプすると撃墜できるモード。

| 日本語名 | 英語名 (Code) | 説明 |
| :--- | :--- | :--- |
| **インベーダーゲームエンジン** | `InvaderGameEngine` | インベーダーゲーム固有の時間経過（Tick）や、敵配列・当たり判定など**ゲームの進行全体**を管理するEntity。 |
| **インベーダー** | `Invader` | 文字列（TargetWord）を保持し、画面上から迫ってくる敵。 |
| **ウェーブ** | `Wave` | インベーダーが一度に出現する群れ・フェーズ。 |
| **防衛ライン** | `DefenseLine` | インベーダーがこのラインに到達するとプレイヤーがダメージを受ける境界線。 |
| **ライフ** | `Life` / `HP` | プレイヤーの体力。0になるとゲームオーバー。 |

### B. 通常タイピングモード (Standard Mode) - 予定

| 日本語名 | 英語名 (Code) | 説明 |
| :--- | :--- | :--- |
| **制限時間** | `TimeLimit` | ゲームの残り時間。 |
| **コンボ** | `Combo` | 連続でミスなくタイピングできた回数。スコアの倍率に影響する。 |

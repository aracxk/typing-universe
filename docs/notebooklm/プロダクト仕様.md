# Typing Universe プロダクト仕様

## 1. プロダクト概要
「Typing Universe」は、複数の異なるタイピングゲームを一つのプラットフォーム上で切り替えて遊べるWebアプリケーションです。

## 2. 現在実装されている機能（現状）
※ 現在は初期セットアップフェーズであり、以下の機能は順次実装予定のものです。

- **インベーダーモード**
  - 文字を持った敵（インベーダー）が画面上部から迫ってくる。
  - 表示された文字を正しくタイピングすることで敵を撃墜できる。
  - 敵が防衛ラインに到達するとプレイヤーのライフが減る。
  - ライフが0になるとゲームオーバー。

- **共通システム**
  - **ログイン・ユーザー登録機能**: なし（ローカルで完結する匿名プレイ）。
  - **スコア管理**: プレイ終了時のスコアや、タイピング速度（WPM）の算出。

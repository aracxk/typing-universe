# Typing Universe プロダクト仕様

## 1. プロダクト概要
「Typing Universe」は、複数の異なるタイピングゲームを一つのプラットフォーム上で切り替えて遊べるWebアプリケーションです。

## 2. 現在実装されている機能（現状）
- **インベーダーモード (Canvas 2D描画)**
  - 文字を持った敵（インベーダー）が画面上部から迫ってくる。
  - 表示された文字を正しくタイピングすることで敵を撃墜できる。
  - 撃墜時や被弾時にパーティクル（爆発）エフェクトが発生する。
  - 敵が防衛ラインに到達するとプレイヤーのライフが減る。
  - ライフが0になるとゲームオーバー。

- **共通システム**
  - **ログイン・ユーザー登録機能**: なし（ローカルで完結する匿名プレイ）。
  - **スコア管理**: プレイ中のスコア加算ロジック。

## 3. 今後のロードマップ・拡張アイデアと要求技術

将来的な「タイピング × 面白さ」の拡張アイデアと、それを実現するために必要となる中核技術の候補リストです。

### 拡張アイデア 1: RPG要素（育成・スキル・ハクスラ）
- **概要**: 敵を倒して経験値を稼ぎ、レベルアップや装備強化を行う。タイピング成功時に必殺技やクリティカルヒットが発動する。
- **要求技術**: **現在の構成（TypeScript/DDD ＋ Canvas 2D）で完全対応可能**。
- **解説**: ダメージ計算やインベントリの状態管理などのルールが増えるだけなので、現在のドメイン層（DDD）を拡張することで実現可能。

### 拡張アイデア 2: オンライン対戦（リアルタイムバトル・協力プレイ）
- **概要**: ランダムマッチングや合言葉で繋がり、タイピング速度で相手陣地にバグを送り込む対戦ゲームや、複数人で巨大ボスを倒すレイドバトル。
- **要求技術**: **WebSocket（双方向通信技術）**
- **解説**: Supabase RealtimeやSocket.ioなどを用い、プレイヤー間の状態を1秒間に数十回同期するサーバー通信技術が必要となる。

### 拡張アイデア 3: 物理演算パズル
- **概要**: 単語が「物理的なブロック」として積み重なっており、タイピングで消すと上のブロックがリアルに崩れ落ちる（テトリスやツムツム風）。
- **要求技術**: **2D物理演算エンジン（Matter.js や Box2D など）**
- **解説**: 座標の単純な足し算ではなく、重力・摩擦・衝突を計算する専用ライブラリの導入が必要。

### 拡張アイデア 4: リズムゲーム（タイピング × 音楽）
- **概要**: BGMのビートに合わせてターゲットが出現し、タイミングよくタイピングすることでスコアが跳ね上がる。
- **要求技術**: **Web Audio API**
- **解説**: ブラウザの音声クロックに合わせて映像と入力をミリ秒単位で厳密に同期させる、高度なサウンドプログラミング技術が必要。

### 拡張アイデア 5: 3D空間（没入型アクション・FPS）
- **概要**: 画面の奥（Z軸）から立体的な敵が迫ってくる、VRやFPS視点のようなタイピングゲーム。
- **要求技術**: **WebGL（Three.js などの3Dグラフィックライブラリ）**
- **解説**: 空間の奥行きや3Dモデルを描画するため、現在のCanvas 2Dから3Dエンジンへのリプレイスが必要となる。
